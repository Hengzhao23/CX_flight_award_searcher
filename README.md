# CX_flight_award_searcher

A Chrome extension that finds Cathay Pacific award seats you can book with Asia Miles, across a whole date range and every cabin.

> Unofficial tool. Not affiliated with Cathay Pacific or Asia Miles.

## Install

1. Download this repo: **Code**, then **Download ZIP**, and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose the unzipped folder.

Needs Chrome 114 or newer.

## Use

1. Click the extension icon. A panel opens beside the page.
2. Enter From and To. Type a city or airport code and pick from the list.
3. Choose a cabin and a date range.
4. Click a search:
   - **Quick check** shows results instantly, but only for some routes.
   - **Full search** works for every route. It opens Cathay in a new tab. Sign in there and keep the tab open while the panel fills in.
5. Click any result to open it on Cathay and book.

Numbers are seats available in First (F), Business (J), Premium Economy (PY) and Economy (Y).
